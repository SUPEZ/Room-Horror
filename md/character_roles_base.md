# База По Ролям Персонажей

## Роли

В игре используются четыре базовые роли персонажей.

- `Warrior`: боевая единица. Основные задачи: защита, атака, сопровождение и удержание опасных зон.
- `Scout`: разведывательная единица. Основные задачи: исследование карты, раскрытие тумана войны, поиск целей и быстрые приказы на перемещение.
- `Worker`: экономическая единица. Основные задачи: сбор ресурсов, строительство, переноска и взаимодействие с объектами мира.
- `Scientist`: единица прогресса и поддержки. Основные задачи: исследования, анализ, открытие новых систем и специальные взаимодействия.

## Текущее Отражение В Коде

В кодовой базе теперь есть отдельный enum ролей:

- `CharacterRoleType`

И отдельный enum задач, через который проверяется доступность задач для роли:

- `CharacterTaskType`

Сейчас в коде первой полноценно поддержанной производственной задачей является `GatherResources`.

## Менеджеры

### CharacterTaskManager

Ответственность менеджера:

- регистрировать всех персонажей, у которых есть `CharacterRoleProfile`
- давать выборку персонажей по ролям
- назначать задачи сбора ресурсов подходящим персонажам
- отслеживать жизненный цикл задач из `CharacterGatherer`
- быть центральной точкой для будущих задач строительства, разведки, исследований и боя

Этот менеджер не заменяет `CharactersCoordinator`.

- `CharactersCoordinator` отвечает за переключение Player/AI контроля
- `CharacterTaskManager` отвечает за роли и назначение задач

### CollectedResourcesManager

Ответственность менеджера:

- хранить глобально собранные ресурсы по `ResourceType`
- получать собранные значения из `CharacterGatherer`
- предоставлять методы добавления, траты, запроса и получения снимка ресурсов
- быть единой точкой учёта накопленных ресурсов экономики

## Настройка Персонажа

Персонаж, который должен участвовать в ролевой и task-системе, должен иметь:

- `Character`
- `CharacterProvider`
- `CharacterRoleProfile`
- `CharacterGatherer`, если роль должна собирать ресурсы
- `CharacterPathfinder3D`, если нужен подход к ресурсам по NavMesh
- `AIBrain`, если задача выполняется через AI

## Базовые Права Ролей На Задачи

Текущие стандартные соответствия роли и задач:

- `Warrior`: `Combat`
- `Scout`: `Scout`
- `Worker`: `GatherResources`, `Build`
- `Scientist`: `Research`

Эти правила сейчас намеренно узкие. Позже их можно расширить через override-настройки, характеристики, перки или технологии.
